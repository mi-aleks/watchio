# Watchio Support

Watchio is a volunteer-maintained, source-only alpha.

- Use [GitHub Discussions](https://github.com/mi-aleks/watchio/discussions) for setup questions and ideas.
- Use [GitHub Issues](https://github.com/mi-aleks/watchio/issues) for reproducible bugs and accepted feature work.
- Read [Troubleshooting](docs/troubleshooting.md) before filing a detection issue.
- Use [private vulnerability reporting](https://github.com/mi-aleks/watchio/security/advisories/new) for security or privacy concerns.

When asking for detection help, share only the runtime, sanitized fixture output, confidence evidence, and Watchio source-health state. Remove usernames, home paths, PIDs, arguments, environment values, and proprietary project names.
